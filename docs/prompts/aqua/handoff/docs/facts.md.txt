# Facts, addresses and sources

Everything here was read on 2026-09-25. Before relying on an address, re-check it with `eth_getCode` and checksum it
with viem's `getAddress`; never retype the letter case by hand.

| Contract | Address | Notes |

| Aqua | `0x1111113ccf1426a8e30e2bff5e005d929bf6a90a` | Same bytecode as on Ethereum, Arbitrum and Base. About 4.9k `Shipped`, 17.0k `Pulled`, 18.4k `Pushed` and 4.8k `Docked` events in the last 20M blocks. |

## 1inch sources

| Source | Notes |
|---|---|
| `github.com/1inch/aqua` | main was `ef24220` when read. Pin your own commit. |
| `github.com/1inch/swap-vm` | Use tag `v1.0.2` to match the deployed router's interface. |
| SDKs | `@1inch/aqua-sdk` 0.3.4 and `@1inch/swap-vm-sdk` 0.4.4 |
| Licenses | `LicenseRef-Degensoft-Aqua-Source-1.1` and `LicenseRef-Degensoft-SwapVM-1.1` |
| Deploy guides | Both repos include one; third-party deployment is allowed. |

SwapVM instruction families:

| Family | Instructions |
|---|---|
| control | `Stop`, `Revert`, `Salt`, `Jump`, `Extruction` |
| guards | `Deadline`, `JumpIf*`, `PrivateOrder`, `Whitelist*`, `OnlyTaker*`, `OnlyTxOrigin*` |
| invalidators | `InvalidateBit`, `InvalidateTokenIn/Out`, `ValidateSeriesEpoch` |
| balances | `Static`, `Dynamic`, `DutchAuctionBalanceIn/Out`, `PiecewiseLinearScale*`, `Decay` |
| curves | `LimitSwap*`, `XYCSwap`, `XYCConcentrateSwap`, `PeggedSwap` |
| rates | `RequireMinRate`, `AdjustMinRate`, `OraclePriceAdjuster`, `BaseFeeAdjuster` |
| fees | `FeeFlatIn/Out`, `FeeProtocol` |

- Opcodes `0xf0`–`0xff` are reserved.
- SwapVM supports ERC-20 only (plus WETH/ETH).
