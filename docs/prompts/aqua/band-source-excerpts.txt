Both read one thing: the oracle that [HAKARI's `HakariOracleHook`](../../vexi-hakari/src/HakariOracleHook.sol) keeps
for any v4 pool that names it as its hook. That hook is OpenZeppelin's `BaseOracleHook`, which is Panoptic's truncated

SOURCE LINES 182-187

The price is the first accepted attempt's TWAP. An attempt whose window has not ended reverts `NotYet(windowEnd)`,
so `MiniBook.settle` reverts and the book's grace waits; a push through the settle window defers settlement to the
next window instead of setting the price. If no attempt is accepted, `NoWindowInBand`, and after the book's grace
MiniBook's unsettled path runs: holders get their premiums back (`refund`), the maker its collateral.
`maxDelay = attempts × settleWindow`, which MiniBook requires to be below its grace. A source is set once per pair
and cannot change.

SOURCE LINES 222-224

- **The ring again.** Settlement reads observations back to `at − settleWindow − bandWindow`. A spam of swaps in
  distinct seconds can wrap the ring before anyone settles; `record` right after the accepted window closes that.
- Chainlink stays the default source; this one is for pairs Chainlink does not cover or does not update.
