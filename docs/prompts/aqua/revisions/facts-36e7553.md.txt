## Aqua at the pinned commit (verified against `src/Aqua.sol` at `ef24220`)

| Function | Signature | Notes |
|---|---|---|
| `ship` | `ship(address app, bytes strategy, address[] tokens, uint256[] amounts) returns (bytes32 strategyHash)` | `strategyHash = keccak256(strategy)`. Caller is the maker. Re-shipping the same hash for the same app reverts (`StrategiesMustBeImmutable`). At most 254 tokens. Emits `Shipped` then one `Pushed` per token. |
| `pull` | `pull(address maker, bytes32 strategyHash, address token, uint256 amount, address to)` | `msg.sender` is the app. Subtracts from the virtual balance (reverts on underflow) and `safeTransferFrom(maker, to, amount)`. Emits `Pulled(maker, app, strategyHash, token, amount)`. |
| `push` | `push(address maker, address app, bytes32 strategyHash, address token, uint256 amount)` | Anyone can call. Requires an active strategy. Adds to the virtual balance and `safeTransferFrom(msg.sender, maker, amount)`. Emits `Pushed`. |
| `dock` | `dock(address app, bytes32 strategyHash, address[] tokens)` | Maker only; must list every token of the strategy. |
| `safeBalances` | `safeBalances(address maker, address app, bytes32 strategyHash, address token0, address token1) view returns (uint256, uint256)` | Reverts if either token is not in an active strategy. |
| `rawBalances` | `rawBalances(address maker, address app, bytes32 strategyHash, address token) view returns (uint248 balance, uint8 tokensCount)` | `tokensCount` 0 = never shipped, 0xff = docked. |

`AquaApp` (base for apps) gives `AQUA`, `nonReentrantStrategy(maker, strategyHash)` and `_safeCheckAquaPush`.

## SwapVM v1.0.2 as deployed on 4663

- `eip712Domain()` on `0x111111338c5091e8440b67b168bae16a668ac0de` returns name `1inch SwapVM v1.0`, version `1.0.2`, chainId 4663.
- `swap(Order order, address tokenIn, address tokenOut, uint256 amount, bytes takerTraitsAndData)` and the same shape for `quote`; `Order = (address maker, uint256 traits, bytes data)`.
- For an Aqua order (`useAquaInsteadOfSignature` bit 254 of `traits`), `hash(order) = keccak256(abi.encode(order))`, and that is exactly the `strategyHash` the maker ships with `Aqua.ship(router, abi.encode(order), tokens, amounts)`.
- `swap()` seeds `balanceIn/balanceOut` from `Aqua.safeBalances(maker, router, orderHash, tokenIn, tokenOut)`, runs the program, then `Aqua.pull(maker, orderHash, tokenOut, amountOut, to)`; the taker either pushes in its `preTransferInCallback` or sets taker flag `useTransferFromAndAquaPush` (0x40) so the router does `transferFrom` + `Aqua.push`.
- Program bytecode is a sequence of `opcode (1 byte) | argsLength (1 byte) | args`. The opcode is an index into the router's `_opcodes()` table, so a program is only valid for the router class it was built against.
