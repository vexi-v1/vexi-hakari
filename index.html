01 / UNISWAP · IMPLEMENTATION

A v4 oracle.
An enforced quote gate.

Read the contracts, then the assertions.
Public implementation · fixed-width band

The integration wraps any IPremium with a pool-derived quote policy. OpenZeppelin supplies the observation engine; Hakari adds a paired-TWAP helper, the band pricer and enforcement inside the option book. The hook records prices; the book decides whether a new option buy can execute.

Hook permissions0x1080
Quote interfaceIPremium.ask(id, n)
Center / live reference3600s TWAP / slot0
Default half-width500 bps = 5%
  1. 01 / OBSERVATION ENGINE

    HakariOracleHook

    Inherits BaseOracleHook. afterInitialize starts the per-PoolId ring; beforeSwap writes raw and truncated cumulative ticks. Hakari’s twaps() returns both average ticks side by side.

    Hakari helper ↗Inherited callbacks ↗
  2. 02 / PRICER WRAPPER

    StabilityBandPricer

    Implements IPremium and IQuoteReference. Reads PoolManager state via StateLibrary and calls hook.observe() directly. status() derives the band; ask() enforces it before calling INNER.ask().

    status() ↗ask(seriesId, n) ↗
  3. 03 / EXECUTION

    OptionBook.buy

    Requotes through the order’s pricer in the buy transaction. Checks the buyer’s maxPremium, collects premium, verifies and pulls collateral through Aqua, then mints ERC-1155 longs. A revert rolls back the buy.

    Buy-time enforcement ↗Inner quote validity ↗

Two execution paths. One reference pool.

CALL-PATH PSEUDOCODE

A / A Uniswap swap updates observations

PoolManager.initialize(key)
  → hook.afterInitialize
    → observationsById[poolId].initialize(...)

PoolManager.swap(key, ...)
  → hook.beforeSwap
    → getSlot0(poolId).tick
    → Oracle.write(timestamp, tick, Δ)
  → execute swap → update slot0

Only afterInitialize and beforeSwap are enabled. beforeSwap returns ZERO_DELTA and no LP-fee override. The band does not reject the reference pool’s swaps.

B / An option buy consumes the reference

OptionBook.buy(orderId, n, maxPremium)
  → check expiry + remaining order quantity
  → quotePremium → band.ask(seriesId, n)
    → status(): slot0 + liquidity + observe()
    → require quoting; require n ≤ sizeCap
    → INNER.ask(seriesId, n) → apply extraBps
  → check maxPremium → collect premium
  → check collateral → writer.provide → Aqua.pull
  → mint ERC-1155 longs

ask() is a view: it computes a per-call limit and keeps no cumulative fill budget. The public INNER is FixedPremium, which checks its deadline and optional original-price anchor.

The arithmetic, including rounding.

BandMath source ↗

Read a geometric TWAP in whole-token units

(raw, trunc) = hook.observe([3600, 0], poolId)
tickAvg = floor((raw[1] − raw[0]) / 3600)
C = priceOf(TickMath.getSqrtPriceAtTick(tickAvg))
Ct = priceOf(TickMath.getSqrtPriceAtTick(
       floor((trunc[1] − trunc[0]) / 3600)))
L = priceOf(slot0.sqrtPriceX96)

C is the raw center, Ct its truncated counterpart, and L the live reference. avgTick floors negative deltas too. priceOf handles either token order and decimals, returning 1e18-scaled quote per whole base token; FullMath avoids intermediate overflow.

Apply the default fixed band

W = 10^18
H = floor(C × 500 / 10_000)
U = ceil(|L − C| × W / H)
cap = floor(50 × (W − U) / W)
extraBps = ceil(2000 × U² / W²)
premium = ceil(INNER.ask(id, n)
               × (10_000 + extraBps) / 10_000)

These formulas apply after valid reference reads, with H > 0 and 0 ≤ U < W. The implementation saturates U for degenerate widths or extreme deviations and refuses if cap is zero. At C = 400 and L = 410: U = 0.5e18, cap = 25, extraBps = 500; an 8 USDG base ask becomes 8.4.

Oracle storage, truncation and same-transaction behavior

Observations are keyed by PoolId in observationsById; stateById tracks index, cardinality and cardinalityNext. A write at the same timestamp is skipped. Raw accumulation uses the pre-swap tick for the elapsed interval. The truncated tick moves toward it by at most MAX_ABS_TICK_DELTA per observation transform.

rawCumulative += tick × elapsedSeconds
truncatedTick = previousTruncatedTick
  + clamp(tick − previousTruncatedTick, −Δ, +Δ)
truncatedCumulative += truncatedTick × elapsedSeconds

observe() can extrapolate the latest observation to now and applies truncation to that transform too. The limit is per transform, not per second. A push and reversal at the same timestamp contributes no elapsed time at the pushed price, but an intervening buy sees the changed slot0.

The fork fixture uses Δ = 250 ticks and requests cardinalityNext = 300 before generating 240 swap observations over two hours. A larger ring retains more observations; it cannot backfill missing history. A sustained price move can still become the rolling center.

Wiring the pool, hook and quote source

PoolKey includes currencies, fee, tickSpacing and the hook address. The hook is selected at pool creation; its low address bits must match AFTER_INITIALIZE | BEFORE_SWAP = 0x1080. An existing pool cannot have this hook added later.

The band constructor checks the base/quote pair in either order, an initialized pool, a nonzero hook and token decimals ≤ 18. It binds the pool and INNER immutably. The owner can change band parameters with setParams; this does not validate an arbitrary hook as a trusted oracle.

Defaults: bandWindow 3600s, nowWindow 0, halfWidthBps 500, maxExtraBps 2000, maxContracts 50, minLiquidity 0. With nowWindow > 0, observe([bandWindow, 0, nowWindow]) supplies a short TWAP for L. referencePriceWad() still reads live slot0 for the independent quote anchor.

Integration scope and remaining limits

The hook’s raw/truncated oracle engine is reused from the pinned OpenZeppelin BaseOracleHook; Hakari’s addition there is the twaps() convenience view. The band reads inherited observe() directly. The integration-specific policy lives in StabilityBandPricer and the option book’s IPremium call.

A sustained move can satisfy the rolling band again; deadline and original-anchor checks remain independent. Repeated buys can exceed one call’s cap. minLiquidity is an in-range liquidity threshold, not a measured manipulation cost. The pool reference and fixed 5% width do not establish fair stock value or a loss guarantee.

HookTwapExpiryPrice is a separate experimental settlement consumer. It can accept a later window or reach a no-window refund path; quote protection before a fill does not establish a fair expiry price.

    What this demonstration establishes
    Aqua pulls exact collateral when an option fills. A guarded SwapVM strategy respects this writer’s unfilled promises. The book enforces the v4-based quote policy. These are local-fork integration results, with test accounts funded using Foundry and a synthetic hooked pool on the canonical manager.
    The maker can still withdraw assets or revoke approval; a later fill then refuses. The guard only constrains strategies that use it. Experimental settlement can accept a later price or refund pooled premiums after no accepted window. It does not establish fair expiry value or production readiness.
