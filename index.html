01 / THE UNISWAP MECHANISM

From pool price
to permission to fill.

Uniswap v4 supplies the reference.
Vexi Hakari turns it into quote rules.

A tokenized-stock pool can keep trading while its underlying market is closed. Vexi Hakari reads that pool’s price and price history before offering a new option fill. Here is how the public integration works.

  1. 01 / PRICE

    Uniswap v4 pool

    The TSLA / USDG reference pool lives in PoolManager. Swaps change its live price; active liquidity describes the depth currently in range.

    getSlot0 · getLiquidityLive price + active liquidity
  2. 02 / HISTORY

    Oracle Hook

    HakariOracleHook builds on OpenZeppelin’s oracle. It records raw and truncated tick histories, then exposes observations for a time window.

    observe([3600, 0])One-hour TWAP center
  3. 03 / QUOTE RULES

    Stability Band

    The pricer compares the live price with that center. Approaching either edge raises the option premium and reduces the maximum size of each fill.

    StabilityBandPricer.askPremium + per-call size cap
ENFORCED ON EVERY BUY

The book checks again at execution.

OptionBook.buy reads the band-adjusted quote before taking the premium or requesting collateral through Aqua. A failed check reverts the buy.

OptionBook.buy↓StabilityBandPricer.ask↓Quote passes → Aqua pulls collateral

What pauses? The band pauses new option fills. The reference pool can still trade: this Oracle Hook records observations and does not apply the option band to Uniswap swaps.

Why read both a live price and a TWAP?

The hook is selected in the PoolKey when a new pool is created. PoolManager calls its enabled callbacks; HakariOracleHook uses afterInitialize and beforeSwap. An existing pool cannot be retrofitted with this hook.

The default center is a one-hour time-weighted average tick, converted to a geometric average price. The default live reference comes directly from the pool’s slot0.

  1. afterInitializeStart the pool’s observation history.
  2. beforeSwapRecord the pre-swap tick, at most once per block timestamp.
  3. swapUpdate the live pool price. A subsequent option buy reads it immediately.

A push and reversal within one transaction adds no elapsed time at the pushed price to the TWAP. An option buy between those swaps still sees the pushed slot0 price and can refuse. Setting nowWindow above zero uses a short TWAP for the live reference instead, with a slower response.

What do raw and truncated mean?

A tick expresses price on a logarithmic scale. The raw series follows the observed tick; the truncated series limits each observation’s tick change using the hook’s configured MAX_ABS_TICK_DELTA.

The band uses the raw TWAP as its center and checks it against the truncated TWAP. If their price difference exceeds the configured half-width, it refuses with SeriesDisagree. Truncation changes the oracle series, not the pool’s traded price.

The history is a finite observation ring. If the requested window is too old or history is too short, the band refuses with ReferenceUnavailable. Increasing observation capacity helps retain a longer history; it does not create past observations.

ReferenceTooThin refuses when active liquidity is below minLiquidity. The default threshold is zero; a deployment must choose a nonzero floor to use that filter.

How does a 5% band change the quote?

For a 400 USDG center, a fixed 5% half-width gives edges at 380 and 420. With an 8 USDG base premium, a 20% maximum extra and 50 contracts per call:

400 USDGAt the center8 USDG · 50
410 USDGHalfway to the upper edge8.4 USDG · 25
420 USDGAt the edge: refused— · 0

Each result shows premium per contract and maximum contracts per call. These are exact illustrative inputs, independent of the recorded fork. Below the center, the same distance produces the same taper.

The size cap rounds down, so quoting can stop just inside the edge when fewer than one whole contract remains. OutsideBand also refuses beyond the edge; SizeCapped refuses a requested quantity above an otherwise open band’s cap.

Three checks beyond the rolling center.

QUOTE VALIDITY

A sustained move can become the new TWAP center. The quote’s separate deadline and optional original-price anchor still apply; only the maker can renew the terms.

FILL CAPACITY

The cap applies per call. Repeated buys can exceed one call’s cap, while remaining order quantity and deliverable collateral still limit execution. An open band alone does not guarantee a fill.

REFERENCE QUALITY

This is a configurable pool-price rule. A fixed 5% band does not establish a fair stock value or a loss guarantee. Experimental expiry settlement uses a separate window-selection policy.

    Aqua pulls exact collateral when an option fills. A guarded SwapVM strategy respects this writer’s unfilled promises. The book enforces the v4-based quote policy.
